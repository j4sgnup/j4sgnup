Migrating legacy .NET Framework 4.8 VB.NET applications to SAML 2.0 / Entra ID using a multi-agent AI workflow, and replatforming to AWS ECS Fargate with Windows containers.<br>AI-augmented backend tooling, multi-agent developer automation pipelines, and Node.js / FastAPI microservices architecture.<br>Azure Bicep IaC patterns for App Service + SQL Server + Key Vault, and MLOps/DVC integration into CI/CD workflows.<br>C#, Java / Spring Boot (from a Node.js background), and local LLM inference with Ollama.<br>Node.js backend architecture, legacy .NET enterprise modernisation (CSLA, WCF, Web Forms), SAML 2.0 / Entra ID migrations, and building multi-agent coding systems with Claude.<br>I built a multi-agent SAML migration system that analyses, plans, and implements auth migrations across N legacy apps — the agents drop into any repo via .github/agents/ with zero manual setup.
